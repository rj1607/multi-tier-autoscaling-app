# Multi-Tier Web Application on AWS

## Tech Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Flask
- Database: MySQL / Amazon RDS
- Containers: Docker
- Cloud: AWS EC2
- Load Balancer: Application Load Balancer
- Scaling: Auto Scaling Group
